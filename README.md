# Thor Operations Command

Thor Operations Command is an internal operations web application for Thor Mobile Truck Wash.

This repository is used to develop and maintain the application interface, supporting workflows, and operational tooling used by authorised Thor personnel.

## Public Notice

This project is intended for authorised use only.

The public repository documentation intentionally does not publish:

- production URLs
- environment variables
- API routes or integration details
- database identifiers
- deployment configuration
- security architecture
- employee, customer, supplier, or operational data
- internal automation details

Do not commit secrets, credentials, tokens, private keys, service-role keys, production data, or sensitive business information to this repository.

## Development

Development is handled by authorised project contributors only.

Use the established internal project notes, environment configuration, and deployment process when working on this application. Public README content should remain high level and should not describe private systems, integrations, routes, credentials, or operational procedures.

## Security

If sensitive information is accidentally committed or exposed, treat it as a security incident:

1. Remove the exposed information.
2. Rotate any affected credentials immediately.
3. Review related access logs and deployment settings.
4. Confirm no production data or privileged access was exposed.
